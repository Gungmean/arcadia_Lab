> **수업 중 배우는 과학 개념을 눈으로 보고 직접 조작하며 이해하는 웹 기반 가상 실험실 플랫폼**

<br>

### 🌐 **[👉 공식 가상 실험실 웹사이트 바로가기 (Vercel)](https://arcadia-lab.vercel.app/)**
### 📝 **[👉 사용자 만족도 평가 & 피드백 남기기 (Google Forms)](https://docs.google.com/forms/d/e/1FAIpQLSdRpS65k_rRiENkOXQtqERFZpdIhjpSssaQSaVSrIKf-ynJyw/viewform?usp=header)**
*(별도 설치 없이 웹 브라우저에서 바로 모든 2D/3D 실험을 체험하고 평가할 수 있습니다.)*

---

## 🌟 프로젝트 소개
학생들이 교과서 속 추상적인 물리/화학 법칙과 수식을 보다 직관적으로 이해할 수 있도록 제작된 인터랙티브 시뮬레이션 플랫폼입니다.  
별도의 프로그램 설치 없이 웹 브라우저에서 바로 다양한 변수(각도, 속도, 주기, 자석 극성, 분자 밀도 등)를 실시간으로 조절하며 시뮬레이션 결과를 관찰할 수 있습니다.

---

## 🔬 구현된 실험실 목록

### 🧪 2D 가상 실험실
| 실험명 | 과목/분야 | 주요 내용 및 조작 요소 |
| :--- | :--- | :--- |
| **🧲 자기장 및 자기력선** | 물리 (전자기) | 막대자석/말발굽자석 배치에 따른 실시간 자기력선 벡터 필드 및 나침반 상호작용 |
| **🌊 물결파 실험실** | 물리 (파동) | 진폭, 파장 조절 및 커스텀 객체(이미지) 업로드를 통한 파동과 매질의 연직 진동 관찰 |
| **☀️ 빛의 반사 실험** | 물리 (광학) | 광원 높이 및 강도 조절에 따른 입사각(\(\theta_i\))과 반사각(\(\theta_r\))의 실시간 측정 |
| **🔮 진자 웨이브 (Pendulum Wave)** | 물리 (역학) | 길이가 다른 진자들의 위상차로 발생하는 주기적 파동 패턴 시각화 |
| **⏱️ 비가역 진자 운동** | 물리 (역학/열) | 공기 분자와의 지속적인 충돌을 통해 운동 에너지가 감쇠하는 비가역 과정 |
| **🟢 경로 추적 단진자** | 물리 (역학) | 줄의 길이(\(L\)), 시작 각도(\(\theta\)), 중력 가속도(\(g\))에 따른 주기 운동 및 궤적 추적 |
| **🚀 포물선 운동** | 물리 (역학) | 초기 발사 속도(\(v\))와 각도(\(\theta\))에 따른 궤적, 최고점, 수평 도달 거리 계산 |
| **💨 기체 분자 확산** | 화학/물리 (열역학) | 격벽 개방 후 분자들의 무작위 충돌과 엔트로피 증가에 따른 비가역 확산 시뮬레이션 |
| **⚖️ 르 샤틀리에 화학 평형** | 화학 II (화학 반응의 세계) | N₂O₄ ⇄ 2NO₂ 반응에서 부피(압력), 온도 조절 및 실시간 농도-시간([C]-t) 수능 킬러 그래프 |

### 🧬 3D 가상 실험실
| 실험명 | 과목/분야 | 주요 내용 및 조작 요소 |
| :--- | :--- | :--- |
| **🧬 3D 세포 소기관 탐색기** | 생명과학 II (세포와 물질대사) | 동물/식물세포 모드, 360° 자유 회전, 소기관 정밀 클릭 포커싱, 엽록체 내부 그라나 틸라코이드 X-ray 투과, 소포체(조면/활면) vs 골지체(시스터나/분비소포) 형태학적 구별, 단백질 분비 경로 팔로우 카메라 |
| **🌟 별의 진화와 블랙홀 생성** | 지구과학 (우주) | 초기 질량과 진화 시간을 조절해 주계열성·초거성·초신성·블랙홀 형성 과정을 관찰하고, 항성 내부·표면의 원소 비율을 스캔 |
| **☀️ 천체의 일주 운동** | 지구과학 (천문) | 내행성/외행성, 관측자 위도, 지구 자전·행성 공전 위치를 조절하여 태양과 행성의 겉보기 운동 및 이각을 분석 |

## 🛠️ 기술 스택 (Tech Stack)
- **Frontend**: Pure HTML5, Modern CSS3 (Glassmorphism Dark Theme UI), Vanilla JavaScript
- **Graphics Engine**: HTML5 2D Canvas API, Three.js (WebGL 3D Rendering Engine), OrbitControls, Tween.js
- **Deployment**: Vercel (초고속 실시간 자동 배포) / GitHub Pages

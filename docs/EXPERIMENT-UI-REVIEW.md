# 기존 실험 UI 통일·검증 기록

## 범위와 기준

기존 실험 12개와 현미경·생명 에너지, 총 14개 실험을 점검했다. 이미 정리한 피스톤·열량계는 이번 변경 대상에서 제외했다. 기준은 아르카디아의 Gmarket Sans, 검정 배경, 인디고 패널, 스카이 블루 강조색과 실제 동아리 로고다. 장치·분자·자기력선·별의 과학적 색상과 계산 모델은 보존했다.

공통 UI는 `assets/arcadia-experiments.css`, 입력의 접근 가능한 이름·도구 키보드 지원은 `assets/arcadia-experiments.js`에서 관리한다. 기존 `assets/arcadia.css`의 브랜드 토큰·글꼴·기본 색상을 함께 사용한다.

## 수정한 문제

- 기존의 고정된 돌아가기 링크를 일관된 브랜드 탐색 바로 바꾸고 실험 목록 접근을 유지했다.
- 문서형 실험의 캔버스와 패널 너비·패딩 때문에 생기던 모바일 넘침을 수정했다. 자석 도구는 휴대폰에서 가로 도구 모음으로 배치한다.
- 슬라이더의 트랙·손잡이·포커스·최소 조작 높이를 통일하고 입력과 라벨을 연결했다. 자석 도구는 Enter/Space로도 추가된다.
- 3D 실험의 모바일 보조 패널을 숨기지 않고 장면 아래에 표시한다. 카메라 비율·렌더러 크기·선택 광선 좌표는 실제 캔버스의 크기와 위치를 사용한다.
- 닫힌 세포 소기관 설명 카드가 화면 밖으로 이동하며 만들던 가로 넘침을 제거했다.
- 현미경의 공통 글꼴·브랜드·기본 테마를 연결했다. 생명 에너지는 기존 테마 선택 기능을 유지하면서 밝은 테마에서도 글자 대비와 돌아가기 링크를 보완했다.

## 조작 표본 검사

- Chromium 모바일 터치 이벤트를 합성해 자석 드래그·드래그 종료와 거울 광원 위치 변경을 확인했다.
- 자석 도구의 키보드 추가, 식물세포 전환, 소기관 설명 열기·닫기를 확인했다.
- 물결파 실험의 이미지 불러오기를 키보드 Enter로 실행해 파일 선택 창이 열리는지 확인했다.
- 세포·별·천체의 카메라 비율이 실제 캔버스 비율과 일치하는지 확인하고, 390×844 ↔ 1100×800 변경 후에도 비율·가로 넘침을 검사했다.
- 천체 자동 자전 버튼이 실제 시간 입력값을 갱신하는지 확인했다.

실제 휴대폰 하드웨어의 터치·GPU 성능, 모든 시뮬레이션의 모든 분기, 색각 특성별 판독성은 이번 표본 검사의 범위에 포함하지 않았다. 이 기록은 UI 검증이며 과학 모델 전체의 재검증을 뜻하지 않는다.

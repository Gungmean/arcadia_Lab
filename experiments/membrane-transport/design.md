# 세포막 수송 · 실제 생물학 구조와 분자 모션

Hero 규모. 장치는 쓰지 않고 실제 인지질 이중층의 절개도·막단백질·세포 형태로 설명한다. 세포외액을 위, 세포질을 아래에 두며 인지질의 친수성 머리와 두 소수성 꼬리를 분리해 그린다.

## 목적 있는 부품

- 인지질 상부 소엽 46개: 구면 음영 머리 46, 두 탄화수소 꼬리 92.
- 인지질 하부 소엽 46개: 구면 음영 머리 46, 두 탄화수소 꼬리 92.
- 이중층 절개 중심부·상단 및 하단 경계·측면 깊이 음영 4.
- 막단백질 두 비대칭 구조 도메인, 입구·결합 부위·출구, 인산화 부위.
- 산소: 각 두 원자로 결합한 분자 배우들. 물: 산소와 두 수소가 결합한 배우들. Na⁺·K⁺는 구별 색상과 이온 기호.
- 포도당: 6탄소 골격 배우, 결합 중 하나의 운반체에 수용되는 공간.
- Na⁺/K⁺ 펌프: 결합 Na⁺ 3개, K⁺ 2개, ATP 1개, ADP 1개, 인산기 1개. 두 입구는 동시에 열리지 않는다.
- 식물 세포: 크기가 고정된 세포벽, 세포막·원형질, 액포, 핵. 동물 세포: 세포막·세포질·핵. 모형 크기 변화는 정성적이다.

## 정확성 계약

단순 확산·촉진 확산은 농도 기울기를 따르며 ATP를 쓰지 않는다. 확산 평형에서도 양방향 이동은 계속된다. 삼투의 용질은 통과하지 않고 물만 이동하며, 저장액에서는 세포 안으로, 고장액에서는 밖으로, 등장액에서는 같은 양이 양쪽으로 이동한다. 식물 세포벽은 고정하고 원형질 분리와 팽압 상태를 구별한다. Na⁺ 수동 이동은 막전위를 생략한 농도 효과만 보여 준다. Na⁺/K⁺ ATPase의 한 회전은 ATP 1개당 Na⁺ 3개 밖으로, K⁺ 2개 안으로이며 인산화·탈인산화와 번갈아 열리는 접근 통로를 구분한다.

모션은 호출자가 주는 0–1 진행률만 사용하며 자체 시계·RAF·CSS 애니메이션이 없다. 1에서 생성물/끝 상태를 유지하고, 임의의 시점으로 되감아도 같은 모습이다. 분자 수·크기·이동 속도는 설명용이며 정량 투과도나 실제 막전위는 계산하지 않는다.
## 확인한 결과

- 한 단백질을 그리는 장면에서는 중앙 공동을 y=176–245에서 유지하고, 닫힘은 위·아래 입구에만 둔다. 일반 통로·GLUT 공동 폭은 36, Na⁺ 3개 결합 공동은 64 SVG 단위다. 표기 크기는 실제 축척이 아니다.
- 물·GLUT 포도당·펌프 이온의 이동은 입구 접근, 중심 통과, 출구 확산으로 나눈다. 막을 지나는 동안 중심 통로를 따라 이동해 단백질 몸체를 가로지르지 않는다.
- Na⁺/K⁺ 펌프는 K⁺ 방출 시 이완된 결합 공동이 마지막 장면에서 초기 모양으로 되돌아간다. 마지막 장면도 실제 구조 변화가 있고, Na⁺ 3개·K⁺ 2개는 새로 생성하거나 복제하지 않는다.
- 식물의 고장액 장면은 고정된 세포벽 안에서 원형질만 줄어든다. 저장액 장면은 원형질이 벽에 닿는 크기까지 채워지고 팽압 상태를 나타낸다. 저장액에서 팽압이 커지면 초기 순유입이 멈춘다는 설명을 구별했다.
- 브라우저에서 36개 기본 장면과 삼투의 용액 3종×세포 2종 변형을 포함한 총 81개 장면을 검사했다. 각 장면의 0→0.5에서 실제 transform 또는 d 변화, 여러 진행률의 유한 좌표, 1에서 끝 상태 유지, 되감은 뒤 같은 끝 상태 재현을 확인했다. 콘솔 오류가 없었다.
- 밝고 어두운 GLUT 결합 공동, Na⁺ 3개 펌프 결합, 물의 통로 통과, 식물 저장액·고장액을 캡처해 확인했다. 원자 기호를 제외한 그림의 설명 글자는 20 SVG 단위 이상이다.

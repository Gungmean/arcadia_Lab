# 현미경 작동구조 실험실

`index.html`을 브라우저로 열면 실행됩니다. 네트워크, 패키지 설치, 빌드 서버 없이 실행되는 독립 HTML입니다. 작업 폴더 최상위의 `현미경 작동구조 실험실.html`도 같은 실행본입니다.

- 광학: 유한 경통 광학계, 대물·접안배율, NA, 파장, 광량, 초점, 분해 한계
- TEM: 전자총, 코일·폴피스, 조리개, 초박 절편, 확대계, 카메라, 전압, 두께, 진공
- SEM: 주사 코일, 시료실, 스텁, SE/BSE 검출기, 래스터 주사, 체류시간, 대전과 코팅
- 모든 장비: 부품 선택 설명, 여섯 단계 재생, 빔 경로, 선택 부품 강조, 확대·이동, 밝고 어두운 테마

장비는 상단 탭 또는 숫자 1·2·3으로 선택합니다. 기본 상태에서 방향키는 과정을 넘기고 Space는 재생합니다. 탭에 포커스가 있으면 방향키로 장비를 전환합니다. 확대된 그림은 드래그하거나 그림에 포커스를 두고 방향키로 이동합니다. 화면 움직임 줄이기 설정에서는 자동 애니메이션을 멈추고 한 단계씩 진행합니다.

## 재생성

```powershell
node prototypes/microscopy-lab/build.mjs
node prototypes/microscopy-lab/build.mjs --audit
node prototypes/microscopy-lab/qa-model.mjs
```

`geometry.mjs`는 Anatomy 키트로 기하를 만들고 모든 실체의 실제 형태를 기록합니다. `model.mjs`가 계산과 설명을, `app.js`가 상호작용과 모식 영상 생성을 맡습니다. HTML에는 코드와 SVG를 모두 포함합니다.

`--audit`는 세 기종 각각의 지지, 겹침·가림 순서, 모형과 그림의 일치 등을 검사합니다. 브라우저 동작 검증 시나리오는 `qa-desktop.json`과 `qa-mobile.json`에 있습니다. Anatomy의 `scripts/drive.mjs`에 `--actions`로 전달합니다. 검증 스크린샷은 `shots/`에 보관합니다.

## 과학적 범위

광학 분해 한계와 상대론적 전자 파장을 식으로 계산합니다. 전자 파장은 장비 분해능과 다릅니다. TEM 직접빔의 가정한 유효 산란 평균 자유 행로 160 nm와 생성된 관찰 영상은 교육용 가정이며 재료의 정량 예측값이 아닙니다. 배율·시야는 모형의 기준 시야를 사용합니다. 전자 궤적, 렌즈장, 실제 미세구조를 정량적으로 계산하는 장비 설계 도구가 아닙니다. 실제 사진을 사용하지 않았습니다.

학습 참고 자료와 계산식은 실행 페이지 하단에서 펼쳐 볼 수 있습니다. 제작 개념과 부품 목록은 `concept.md`에 있습니다.


과학적 타당성 검토와 수정 내역, 근거 자료 및 적용 한계는 [SCIENCE-REVIEW.md](SCIENCE-REVIEW.md)에 정리했습니다. 광학·TEM·SEM의 별도 서브에이전트 독립 검토와 수정본 재검토를 수행했습니다.

# 전자 현미경 중심 개선과 실험실 통합

## 이번에 반영한 개선

- TEM: 70 nm 기준·200 nm 두꺼운 절편·좁은 조리개를 같은 초기 조건에서 비교하는 실험 버튼 추가. 관련 시료/대물렌즈 단계로 이동하며 관찰 목적과 기준 대비 가정한 검출 신호를 표시한다.
- SEM: SE 기준·BSE 비교·코팅 해제·긴 주사를 한 조건씩 비교한다. 시야와 프레임 시간, 정성 대비·잡음·대전의 차이를 설명한다.
- 전압이 현재 전자 파장만 계산한다는 범위를 전자 현미경 조절부에 항상 표시한다. 실제 해상도 개선으로 오해하지 않게 한다.
- 수동 조절 시 비교 실험의 선택 표시를 해제해 현재 조건이 프리셋과 같다고 오해하지 않게 한다.
- `experiments/microscopy/index.html`에 실행본을 생성하고, 생명과학 목록에 현미경 카드를 추가했다. 전자 현미경 중심으로 TEM에서 입장하며 세 기종 모두 전환 가능하다.
- 실험 목록 복귀 링크, TEM 절개도 썸네일, 검토 문서와 재생성 경로를 추가했다.

## 다음 개선의 우선순위

1. **주사에 따라 실제로 누적되는 SEM 영상:** 현재 미리 만든 모식 영상 위에 주사 진행을 표시한다. 픽셀별 검출 신호를 누적하고 프레임 완료/재주사를 구현하면 주사식 영상의 의미가 더 분명해진다.
2. **TEM 영상면·회절면의 비교:** 현재 명시야 영상만 다룬다. 후초점면·대물조리개를 별도 확대 장면으로 보여 주고, 영상/회절 모드를 정확한 공액면 모델로 구분하는 것이 다음 과학적 확장이다.
3. **실제 전자광학 변수:** 작업거리·탐침 전류·비점수차·배율 보정은 현재 미계산이다. 장비·시료별 검증 자료를 확보한 뒤 도입해야 한다. 임의의 숫자를 실제 성능 예측값처럼 추가하지 않는다.
4. **관찰 기록:** 기준/변경 영상 나란히 저장, 관찰 노트, 학습 확인 질문을 추가하면 수업 비교 활동에 활용하기 쉽다.

현재 모델의 검증 범위와 근거는 [SCIENCE-REVIEW.md](SCIENCE-REVIEW.md)를 따른다. 이번 통합은 로컬 저장소 반영이며 공개 사이트 배포는 수행하지 않는다.

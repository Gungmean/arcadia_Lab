# 기존 2D 실험 9종 문구 검토

검토일: 2026-11-14 (Asia/Seoul). 대상은 HTML 본문·문서 제목·Canvas에 그리는 문구·JavaScript에서 갱신하는 상태 문구다. 이 문서는 유지보수 기록이며 실험 화면에 노출되지 않는다.

## 공통 기준

- 실험과 무관한 버전 수식어, 장식용 이모지, 의미가 중복되는 영어 병기, 홍보성 표현을 걷어냈다.
- 과학 용어를 삭제하기보다 쉬운 설명을 붙였다. 식·기호·단위·숫자·조작 범위·모형의 한계는 보존했다.
- 브랜드·동아리·제작팀 표시는 사이트 식별과 제작자 표시이므로 공통 내비게이션과 푸터에 남겼다. 자석 화면 내부의 중복 제작자 문구만 조작 안내로 교체했다.
- CSS·식별자·이벤트 연결·수치 계산·상태 분기 조건은 수정하지 않았다. 평형 복귀 시 오래된 설명이 남지 않도록 기존 평형 분기에 설명 문구 할당 한 줄을 추가했다. 소스 주석은 사용자에게 보이지 않으므로 문구 삭제 대상으로 삼지 않았다.

## 검증

- 9개 HTML의 모든 인라인 JavaScript를 Node `vm.Script`로 구문 검사했다.
- 처음 문구 교체 후에는 변경 전후 JavaScript의 문자열을 제외한 코드가 같음을 확인했다. 이후 평형 설명 갱신 누락을 바로잡기 위해 `le_chatelier.html`의 기존 평형 분기에 `theoryTip` 표시 문자열 할당 한 줄만 추가했다. 계산·분기 조건·함수 호출은 동일하다.
- id/class/이벤트 속성/링크/입력 type·min·max·step·value가 변경되지 않았는지 비교했다.
- 모든 인라인 CSS가 변경되지 않았음을 확인했다. 새 의존성은 추가하지 않았다.
- 브라우저 화면 재검증은 상위 작업에서 일괄 진행한다.

## 평형 설명 갱신 수정

`le_chatelier.html`은 평형 복귀 분기에서 상태 배지만 갱신하고 `theoryTip`을 갱신하지 않아 앞선 정반응/역반응 설명이 남았다. 기존 평형 분기에 설명 문자열 할당만 추가해 “정반응과 역반응의 속도가 같아 농도가 일정하게 유지됩니다. 두 반응은 계속 일어납니다.”로 표시한다. 반응량 계산이나 평형 판정 조건은 바꾸지 않았다. 수정 후 JavaScript 구문 검사와 기존 분기에 설명이 할당되는지 확인했다.

# 실험 화면 표현 검토

검토일: 2026-11-14 (Asia/Seoul).

## 범위와 기준

현재 실험 목록(2d.html)에서 연결되는 16개 실험의 제목, 안내, 버튼, 동적 상태·해설, 그림 속 문구를 검토했다. 첫 화면·실험 목록·3D 목록과 기존 어두운 테마, 독립 HTML 복제본도 함께 확인했다. 사용하지 않는 archive와 tmp의 과거 실험·검증 자료는 현행 화면의 문구로 취급하지 않았다.

이해에 필요한 과학 용어·식·단위·수량·범례·조작 안내·모형의 한계·출처는 유지했다. 장식용 영어, 홍보·버전 수식어, 개발 구현 설명, 관찰 내용과 관계없는 비유는 삭제하거나 관찰 대상을 직접 설명하는 말로 바꿨다. 동작 선택자·입력 범위·시뮬레이션 계산·색과 배치는 바꾸지 않았다.

## 실험별 검토 기록

- [기존 2D 실험 9개](classic-review.md): 자기장, 물결파, 반사, 진자 3종, 포물선, 확산, 화학 평형.
- [현미경·열량계·피스톤](instruments-review.md): 제공 HTML과 생성 원본의 같은 문구를 부분 동기화.
- [세포 구조·천문 실험](cell-space-review.md): 세포 구조, 일주 운동, 별의 진화 및 독립 세포 HTML.

별 실험에서 원소 구성으로 오인할 수 있던 사건의 지평선·강착원반의 표는 관측 가능 범위 설명으로 교체했다. 원소 막대의 임의 비율은 실제 측정값으로 보이지 않게 정리했다. 이는 시뮬레이션의 물리량 계산 변경이 아니라 잘못된 표시의 수정이다.

화학 평형 실험에서는 평형 복귀 시 앞선 정·역반응 설명이 남지 않도록, 해당 상태에서 동적 평형 설명을 갱신하는 표시문 할당을 추가했다. 반응 계산과 평형 판정 조건은 그대로다.

## 검증

- 현행 16개 실험과 첫 화면·두 목록·피스톤 어두운 테마, 총 20개 경로를 실제 Chrome에서 열었다. 탐색 실패·실행 예외·가로 넘침이 없었다.
- 생명 에너지 40개 장면의 설명을 확인했다. 최종 장면의 표시 텍스트가 SVG 경계에서 잘리지 않는지도 검사했다.
- 생명 에너지·피스톤·열량계 모델 검사 19개 통과.
- 수정한 JavaScript 및 각 실험의 인라인 스크립트 문법 검사 통과.
- 생성 원본이 있는 기구 실험은 전체 빌드를 덮어쓰지 않고 같은 문구만 동기화했다.
- 문구 정리 단계에서는 기존 별·화학 평형 CSS의 대비·발광 관련 경고를 별도로 기록했다. 이후 디자인 검사 요청에 따라 아래의 좁은 범위만 수정했으며 새 예외는 추가하지 않았다.

실제 화면의 문구 수집 결과와 검증 출력은 tmp/copy-audit/에 보관한다.

## 후속 디자인 검사

- 생명 에너지의 밝은 테마 안내 글자만 어두운 색으로 조정했다. 실제 글자·배경 대비는 5.49:1이다.
- 화학 평형 설명 상자의 4px 왼쪽 강조선을 1px 전체 테두리로 바꾸고 안쪽 여백을 16px로 조정했다.
- 화학 평형의 수치 칸에 12px 여백을 추가했다.
- 같은 파일에서 추가로 확인된 열 표시 글자와 버튼에 마우스를 올렸을 때의 대비는 각각 5.67:1, 13.13:1로 개선하고, 슬라이더 손잡이의 발광 그림자를 제거했다.
- 390px와 데스크톱 화면에서 가로 넘침·실행 예외가 없음을 확인했다. 과학 문구·수식·반응 계산은 변경하지 않았다.

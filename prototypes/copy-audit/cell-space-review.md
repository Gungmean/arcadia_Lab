# 세포·천문 실험 문구 검토

## 조사 범위

- `experiments/cell_structure_3d.html`: 초기 HTML, 소기관 설명 데이터, 분비 경로 안내, 동물·식물 모드 전환 문구.
- `experiments/celestial_motion.html`: 관측 조건, 관측자 시점, 상태 표시, 자동 재생과 행성 배치의 동적 문구.
- `experiments/star_evolution.html`: 진화 조건, 단계·상태 설명, 위치별 원소 표시와 관측 안내.
- `세포 구조 실험실.html`: 별도로 동작하는 단일 HTML 관찰 그림. 현행 3D 실험의 생성 원본은 아니며, 이 파일의 정적·동적 문구를 함께 검토했다. `prototypes/cell-anatomy/build.mjs`는 해당 프로토타입 디렉터리에만 출력하므로 이번 수정 파일의 재생성 원본이 아니다.

## 오해를 유발하는 원소 표기 제거

- 사건의 지평선을 `시공간 곡률(특이점) 99.9%`, `정보(Hawking Rad.) 0.1%`라는 원소 구성처럼 표시하던 표를 삭제했다. 대신 지평선 안쪽에서 나온 빛이 외부 관측자에게 도달하지 않아 원소 구성을 직접 관측할 수 없다는 설명을 표시한다.
- 강착원반의 `초고온 붕괴 플라즈마`, `양자 축퇴 가스` 등을 원소 함량으로 나열하던 표도 삭제했다. 고온의 이온화된 기체가 빛을 내며, 이 모형이 원소별 함량을 계산하지 않는다는 설명으로 대체했다.
- 다른 층의 원소 이름과 이해를 돕는 막대는 유지하되, 실제 질량비처럼 보이던 숫자 `%`는 제거했다. 원소 막대가 실제 함량이나 측정값이 아닌 구성 예시임을 안내한다. 질량·온도·반지름 계산 및 시뮬레이션 진행 값은 변경하지 않았다.

## 유지한 표현

- 크리스타·틸라코이드·그라나·스트로마·핵공·cis/trans면, mRNA·rRNA·ATP 등 개념을 구분하는 과학 용어.
- 내합·외합·합·충·구·최대이각, 주계열성·축퇴압·사건의 지평선·강착원반 등 관찰 대상의 이름.
- 회전·확대·선택·재생 안내와 모형의 크기·시간·궤도 가정, 출처 링크.
- 조작 선택자, DOM ID, 소기관 식별 키, 물리 수치와 시뮬레이션 동작.

## 검증

- 네 파일의 인라인 JavaScript 각각 `vm.Script` 구문 검사 통과.
- 네 파일의 DOM ID 목록은 기존 버전과 동일.
- 별의 중심핵·표면·강착원반·사건의 지평선 표시 함수를 가상 DOM에서 실행해 설명과 영문 중복 제거가 정상 반영되는지 확인.
- `git diff --check` 통과.
- 별 실험의 기존 색 대비·빛나는 그림자 스타일에 대한 디자인 훅 경고가 발생했다. 이번 변경은 문구와 잘못된 원소 설명 표에 한정했고 기존 CSS를 수정하거나 해당 경고를 예외 처리하지 않았다.

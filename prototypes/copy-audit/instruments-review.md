# 현미경·열량계·피스톤 표현 점검

## 점검 범위

- 현미경: `experiments/microscopy/index.html`, 재생성 원본 `prototypes/microscopy-lab/{build.mjs,app.js,index.html}`, 루트의 동일 실험 복제 HTML.
- 열량계: `experiments/calorimetry/{build.mjs,app.js,index.html}`.
- 피스톤: `experiments/piston/{build.mjs,geometry.mjs,index.html,dark.html}`. 별도 삽입 템플릿 `law.mjs`의 영어 표제도 함께 동기화했다.
- 각 실험의 geometry·app 파일에서 사용자 표시 문자열을 확인했다. 수정 필요가 없는 파일은 그대로 두었다. 존재하지 않는 light/dark HTML은 새로 만들지 않았다.
- 작업 경로에서 AGENTS.md는 발견되지 않았다.

## 유지한 표현과 정보

- TEM·SEM·SE·BSE는 장비·검출 신호를 구별하는 과학 용어이므로 유지했다.
- Rayleigh, NA, FN, FOV, Gaussian, 전자 파장 식, 열역학 수식과 단위는 계산 원리와 가정을 설명하므로 유지했다.
- 모식 영상이라는 한계, 실제 축척과 다른 표시 속도, 진공 조건, 회절·산란 계산의 한계, 전자 파장과 장비 분해능의 차이를 유지했다.
- 열량계 보정, 반응계·주위의 구별, 열량계 열용량, 외부 열교환, 엔탈피의 부호와 제한 반응물을 유지했다.
- 피스톤의 등압·등적·단열 조건, 일정 외부 하중, 열·일·내부 에너지의 부호와 계의 경계를 유지했다.
- 계산 수치·제어 변수·수식·이벤트·SVG 경로·부품 좌표·출처 링크는 변경하지 않았다.
- 브랜드와 참고 자료의 기관명은 유지했다.

## 동기화와 검증

전체 build를 실행하지 않고 해당 문자열만 부분 치환했다. 따라서 생성 HTML에 이미 존재하던 다른 변경과 도형은 보존했다. 재생성용 build/app 템플릿과 기존 HTML의 같은 표시 문구를 함께 고쳤으며, 기존 피스톤 dark.html도 같은 표현으로 수정했다.

- 수정한 JS/MJS 문법 검사 통과.
- 현미경 원본·배포본·루트 복제본, 열량계 index, 피스톤 index/dark의 인라인 스크립트 파싱 통과.
- 브라우저에서 세 실험 진입, 열량계 보정 전환, 현미경 SEM 전환 후 새 문구 확인. 세 페이지 모두 console clean.
- 대상 소스에서 FIG/CUTAWAY/BRIGHTFIELD/PROCESS/COMPONENT 및 불필요한 영어 표제 잔존 점검 완료. 코드 주석 속 SVG 등 개발 용어는 화면에 표시되지 않으므로 그대로 두었다.
